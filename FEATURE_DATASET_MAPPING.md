# Feature-to-dataset mapping and case design

Audit date: 2026-11-23. This is a **future manual case specification**, not executed tests. No fixtures were generated. See [inventory](CODEBASE_FEATURE_INVENTORY.md) for source/functions and [manual checklist](MANUAL_BROWSER_TEST_PLAN.md) for actions. `D`=200-bp random-weight demo, `H`=pinned 2,114-bp pretrained GM12878, `L`=compatible registered local model. D results check software only, never pretrained biology.

Readiness: **Ready** means existing input can exercise the code, not that this audit ran it. **Conditional H** means original checkpoint/registration availability is not established: its recorded cache is absent in the visible filesystem. Current live server configuration was not queried. **Needs fixture** means proposed text/image below, not a file secretly generated. Manual editor changes must not overwrite original input files.

## Valid, invalid and edge cases with independent verification

The primary matrix supplies one valid case per feature. Every row below adds an invalid and useful edge case. “Edit” means a future temporary browser editor change, never modification of the source fixture. Minimal absent fixtures are described rather than generated.

## Missing fixture queue — describe only, do not create

1. Dedicated eight-distinct-50bp `sequence,label` training sample with truthful GC labels;7-row negative variant optional. This is a workflow test, not biology.
2. Dedicated 1–3-row **biological** variant CSV, copied from parent with matching1-based1057 context and IDs, keeping source24rows untouched. Up to12rows fits H zero-shuffle budget.
3. Minimal still64×64PNG avatar; separate invalid/oversized image fixtures and metadata-bearing input for normalization/privacy checks.
4. Labeled biological training/validation/test CSVs with externally controlled chromosome/locus/similarity partition. Existing measured DNase table contains sequences/labels but is not the supported training schema or an authorized adaptation split; do not repurpose chr11 evaluation as training.
5. Biological JASPAR/MEME TF resource and independently annotated positives/negatives; a second independent compatible pretrained model. Both absent; no download now.
6. UTF-8BOM/CRLF/non-UTF8/emptyupload, duplicateID, size/record/hit-budget limit fixtures, and formula/Unicode-ID browser-export fixtures. Many gate JSON cases hold literals rather than direct user-uploadable files; describe desired bytes/values first, do not fabricate file existence.
7. Isolated disposable history/account/job state for pagination/restart/failure testing; never corrupt or delete saved evidence. Current SQLite/test archives are not interchangeable with a live guest session.
