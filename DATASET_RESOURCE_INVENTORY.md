### Important allele/build/coordinate caveat

The dsQTL column named `reference_sequence` retains **published allele1**, not necessarily the genomic reference: allele1 matches hg19 for only 183/1,000 sampled rows (817 do not); population counts 5,437/22,836. All sampled pairs internally have one change at zero-based 1056 / displayed **1057**. The prep uses [benchmark_gm12878.py](scripts/benchmark_gm12878.py) `allele_sequences`/`prepare`. By contrast, engine-only [workflows/vep.py](workflows/vep.py) `_fetch_context` centers its even-length 2,114-bp windows at displayed **1058**. Synthetic trained-model fixtures also use 1058. Always use the position belonging to the supplied sequence; do not “correct” one convention into the other. Whole biological dsQTL evaluation averages forward/RC effects, then ranks absolute allele2-minus-allele1; a single UI forward delta is not that final benchmark statistic.
