## Correctness ladder

1. **UI:** labels, state, focus, errors, screenshot and exact action sequence.
2. **Input contract:** IDs/count/length/build/position/task/hash match the actual fixture. Friendly hints do not replace backend validation.
3. **Arithmetic:** alt−ref; absolute ranking per task; hand QC/metrics; nondecreasing design objective; PWM formula. Use full-precision JSON, not rounded HTML.
4. **Cross-workflow:** identical input/model/task gives the same F02/F08 delta; same-spec F14 difference0; CSV/FASTA match JSON. Do not compare different synthetic seeds because filenames look similar.
5. **Independent evidence:** G4 numerical oracle/G5 gradient checks are bounded backend evidence, not a newly executed browser test. Measured DNase/dsQTL benchmarks are separate from constructed-SNV, random-weight, GC-label or motif demonstrations.
